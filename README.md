# 🎄 Christmas List

A web app for keeping your Christmas wishlist and planning the gifts you give.

## Features

- **My wishlist**: add items with a link, price, priority, and notes. You can edit and remove them.
- **Gift giving**: add the people you're shopping for with an optional budget, and track each gift idea as Idea → Bought → Wrapped. Spending shows against each person's budget.
- A countdown to Christmas.

Data is saved in your browser (localStorage) for now.

## Roadmap

- [ ] Shared family lists: accounts, sharing your wishlist, and letting others secretly claim items

## Development

```bash
npm install
npm run dev     # start the dev server
npm run build   # type-check and build for production
npm run lint
```

Built with React, TypeScript, and Vite.
